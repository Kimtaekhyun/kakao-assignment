# Todo List Dashboard (Assignment-2)

카카오 테크 캠퍼스 2단계 과제로 제작된 주간 캘린더 기반의 할 일 관리(Todo List) 애플리케이션입니다.

## 🚀 주요 기능

### 1. 할 일 관리 (CRUD)
- **추가**: 입력창을 통해 새로운 할 일을 추가할 수 있습니다.
- **수정**: 등록된 할 일의 내용을 수정할 수 있습니다. (수정 중 취소 가능)
- **삭제**: 더 이상 필요 없는 할 일을 삭제할 수 있습니다.
- **완료 처리**: 할 일의 완료 상태를 토글할 수 있습니다.

### 2. 주간 캘린더 (Weekly Calendar)
- **날짜 선택**: 주간 캘린더에서 특정 날짜를 선택하여 해당 날짜의 할 일을 관리할 수 있습니다.
- **주 단위 이동**: 이전/다음 버튼을 통해 주 단위로 이동할 수 있습니다.
- **오늘로 이동**: 언제든 '오늘' 날짜로 즉시 돌아오는 기능을 제공합니다.
- **카운트 표시**: 각 날짜별로 등록된 할 일의 개수를 캘린더 상에서 확인할 수 있습니다.

### 3. 필터링 및 정렬
- **전체/진행 중/완료**: 탭을 통해 상태별로 할 일을 필터링하여 볼 수 있습니다.

### 4. 데이터 유지 및 검증
- **LocalStorage**: 브라우저를 새로고침해도 할 일 데이터와 달력의 주간 상태가 유지됩니다.
- **데이터 검증**: 빈 입력값 방지 및 날짜 형식 검증 등 무결성을 위한 스키마가 적용되어 있습니다.

## 🎨 UI/UX 디자인
- **대시보드 레이아웃**: 넓고 쾌적한 카드형 디자인을 적용하여 정보 인지성을 높였습니다.
- **반응형 디자인**: 모바일 환경에서도 최적화된 화면을 제공합니다.
- **애니메이션**: 할 일 추가 및 리스트 전환 시 부드러운 애니메이션 효과를 적용했습니다.

## 🛠 기술 스택
- **Framework**: React (Vite)
- **Styling**: Vanilla CSS (Custom Properties)
- **State Management**: React Hooks (useState, useEffect, useMemo)
- **Data Persistence**: LocalStorage API
